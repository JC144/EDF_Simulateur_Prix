La méthode

Comment fonctionne le calcul ?

Le simulateur rejoue votre consommation réelle, demi-heure par demi-heure, sur la grille tarifaire de chaque offre suivie :

Voir la liste des tarifs actuellement suivis.

01

L'abonnement annuel est proratisé au jour près sur la période importée.

02

Pour les offres à prix variables, les vrais calendriers sont appliqués : couleurs des jours Tempo, jours EJP et plages d'heures creuses propres à chaque contrat.

03

Les offres indexées sur le marché utilisent les prix spot réels (EPEX, via energy-charts.info).

04

Les grilles tarifaires sont versionnées dans le code avec leur date de mise à jour et actualisées régulièrement à partir des documents officiels des fournisseurs.

FAQ

Questions fréquentes

Pourquoi le résultat diffère-t-il de ma facture ?

Nous appliquons les tarifs en vigueur aujourd'hui à votre consommation passée. Si un tarif a changé entre-temps, le montant simulé peut donc différer de ce que vous avez réellement payé. L'objectif est de comparer les offres entre elles à consommation identique, pas de reconstituer vos factures.

Comment le comparateur trouve-t-il l'offre la moins chère ?

Le simulateur calcule le coût total de chaque offre sur votre historique de consommation, sans le modifier. Il montre quel abonnement aurait été le moins cher avec vos habitudes actuelles. Vous pourrez peut-être économiser davantage en décalant ensuite certains usages vers les heures creuses.

Mes données Linky sont-elles envoyées quelque part ?

Non. Tout est calculé localement dans votre navigateur : votre fichier de consommation n'est jamais transmis à un serveur.
Le site n'utilise ni cookies, ni trackers, ni outil de mesure d'audience.
Vous pouvez même exécuter l'outil sur votre machine depuis son code source.

Quelles données faut-il pour un résultat précis ?

Il vous faut un export de consommation Linky au pas de 30 minutes — pensez à activer le suivi à la demi-heure sur votre compteur si ce n'est pas déjà fait — et idéalement au moins un an de données (de mars à mars) pour couvrir toutes les saisons.

Les résultats sont-ils fiables ?

Les calculs sont testés régulièrement contre des cas réels, mais nous n'excluons pas de légères différences. Si vous constatez un écart, signalez-le via vos retours sur GitHub : nous restons réactifs pour affiner les résultats.

L'outil est-il gratuit et open source ?

Oui. Le comparateur est entièrement gratuit, sans inscription, et son code source est en accès libre sur GitHub.
Vous pouvez vérifier comment il fonctionne, l'exécuter en local ou contribuer, par exemple en mettant à jour les grilles tarifaires.

Export automatique Enedis (script)

Ce script récupère automatiquement toute votre courbe de charge à la demi-heure (jusqu'à ~2 ans) depuis votre espace client Enedis. Il s'exécute dans votre navigateur et ne communique qu'avec enedis.fr : aucune donnée n'est envoyée ailleurs.

  1. Connectez-vous à votre espace particulier Enedis (et vérifiez que la « Collecte de la consommation horaire » est activée dans « Gérer l'accès à mes données »). En cas de doute sur votre connexion, ce lien doit afficher du texte brut (JSON) et non une erreur.
  2. Facultatif : saisissez ci-dessous votre numéro de PRM / PDL (14 chiffres, sur votre facture ou votre compteur Linky) — sinon le script vous le demandera.
  3. Copiez le script avec le bouton ci-dessous.
  4. Sur l'onglet de votre espace client (mon-compte-particulier.enedis.fr, n'importe quelle page), ouvrez la console du navigateur : touche F12 puis onglet « Console ».
  5. Sous Chrome/Edge, si le collage est bloqué, tapez allow pasting puis Entrée.
  6. Collez le script, appuyez sur Entrée et laissez tourner : une barre de progression s'affiche en bas à droite (comptez ~2 minutes pour 2 ans de données).
  7. Glissez le fichier "conso-courbe-30min_… .csv" téléchargé dans la zone d'import ci-dessus.
Exporter sa consommation depuis TotalEnergies
  1. Rendez-vous sur le site de TotalEnergies votre consommation.
  2. Cliquez sur "Électricité"
  3. Sélectionnez "Heure"
  4. Cliquez sur le bouton Télécharger, cela va télécharger les données depuis la mise en place de votre Linky, dans une limite de 3 ans
  5. Utilisez le fichier "0123456789-NOM-PRENOM.csv"
Exporter sa consommation depuis Strasbourg Électricité Réseaux
  1. Rendez-vous sur le site Strasbourg Electricité Réseaux.
  2. Cliquez sur "Courbe de charge".
  3. Choisissez, si possible, une période d'au moins 1 an via le bouton "Personnalisé".
  4. Cliquez sur "Exporter les données"
  5. Utilisez le fichier (sans le renommer) "export_courbe_charges.csv"
Exporter sa consommation depuis Home Assistant
  1. Récupérez votre export depuis votre interface
  2. Utilisez le fichier (sans le renommer) "history.csv"
Les données importées ne sont pas valides.

Résultats de la simulation

Attention:
  • Ce résultat est une simulation basée sur votre consommation passée avec les tarifs actuels.
  • Le coût de l'abonnement est intégré au prorata journalier.
  • Il existe des subtilités contractuelles entre les offres dites "de marché" (à la main de l'opérateur) et les offres TRV (règlementées) qui doivent être étudiées au cas par cas suite au classement des résultats obtenus ci-dessous.
  • Nous faisons de notre mieux pour garder les tarifs à jour, mais pensez à les vérifier avec vos fournisseurs avant de souscrire un contrat.

À propos

À propos de ce comparateur

Ce comparateur est un outil open source basé sur votre historique réel de consommation Linky plutôt que des profils types pour comparer les abonnements d'électricité. En quelques clics, vous obtenez le prix que vous auriez réellement payé avec les tarifs actuels.
Vos données sont traitées en local dans votre navigateur : aucune donnée n'est envoyée vers un serveur, vous pouvez même l'exécuter sans internet.
Le site n'est rémunéré ni par les fournisseurs, ni par la publicité, vos dons me permettent de le maintenir et de financer son développement (nom de domaine, licenses).
